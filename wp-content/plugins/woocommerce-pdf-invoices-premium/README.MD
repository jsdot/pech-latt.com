**How to install**
1. Unrar/Unzip.
2. Upload woocommerce-pdf-invoices-premium folder to plugins directory with FTP program like FileZilla.
3. Activate plugin within WordPress plugins page.

Note: The premium version requires the free Invoices for WooCommerce plugin!

**How to upgrade**
1. Download the new version from your account on https://wcpdfinvoices.com/my-account.
2. Unrar/Unzip.
3. Backup old Invoices for WooCommerce Premium plugin just to be sure and delete plugin.
4. Upload woocommerce-pdf-invoices-premium folder to plugins directory with FTP program like FileZilla.

Note: The premium version isn't always backwards compatible with the free version. Please keep your plugins updated!
